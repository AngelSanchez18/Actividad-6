## Cuestionario 

Al finalizar el ejercicio, se responden los siguientes puntos clave sobre la estructura y documentación del proyecto:

### 1. ¿Para qué sirve `package`?
Sirve para englobar, agrupar y organizar clases e interfaces relacionadas dentro de un espacio de nombres (*namespace*) único. Esto evita conflictos de nombres entre clases y facilita el control de acceso y mantenimiento del código.

### 2. ¿Para qué sirve `import`?
Permite acceder y utilizar clases, interfaces o paquetes completos que se encuentran definidos fuera del archivo actual o en otros paquetes, evitando tener que escribir el nombre cada vez que se utilicen.

### 3. ¿Qué relación existe entre paquete y directorio?
La estructura de paquetes declarada en el código (`package com.sistema.biblioteca;`) se refleja físicamente en el sistema de archivos como una jerarquía de carpetas/directorios (`com/sistema/biblioteca/`).

### 4. ¿Qué es Javadoc?
Es una herramienta estándar que genera automáticamente documentación en formato HTML a partir de los comentarios estructurados escritos en el código, facilitando la comprensión de las clases, métodos y atributos del sistema.

### 5. ¿Qué diferencia hay entre `//` y `/** ... */`?
* `//`: Define un comentario de una sola línea, destinado a notas rápidas o explicaciones internas de código que el compilador ignora.
* `/** ... */`: Define un bloque de comentario de documentación (Javadoc), procesable por herramientas externas para generar la documentación oficial del código.
